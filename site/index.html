What it finds

The parts of your bill nobody shows you.

Every turn re-sends the whole conversation. When the prompt cache is warm that costs little. When it goes cold, you pay to write it all again. Most of the waste hides there, and in noisy tool output that sits in context for the rest of the session.

01 · Cache-miss forensics

Know why the cache broke, and what it cost.

Receipts finds every call that rebuilt a cache it could have read, names the likely cause and prices the difference.

Long break, model switch, prompt or MCP tools changed, or an expected compaction.

Lost to cache misses .................. $93.94
  23x cache expired (long break) ...... $80.89
  3x prompt or tools changed .......... $13.05

02 · Live cache countdown

See the clock before you step away.

The status line shows how long your cache stays warm and what the next turn will cost if it expires. Plus spend, burn rate and context use.

Example lines: a warm cache, then a cold one.

03 · Lossless trimmer

Drop the noise. Keep every error. Lose nothing.

A hook shrinks the output of test suites, installs, builds and logs before Claude reads it. Repeated lines collapse, every warning and error stays, and the full output is saved to disk with its path shown to Claude. Reads like cat, grep and git diff are never touched.

A real passing run of 401 tests: 3,605 tokens down to 104.

04 · A/B bench

Test any plugin's claims on your own repo.

Run the same task with and without a plugin in throwaway local clones of your repo, with no remotes. Compare real cost, turns, time and whether your tests pass.

$ receipts bench \
    --task "fix the failing test" \
    --plugin ../some-plugin \
    --check "npm test" \
    --runs 3 --model haiku

How it counts

Numbers you can check.

From your own transcriptsClaude Code logs the exact token usage of every API call. Receipts reads those files and counts each call once.
List prices, per modelFresh input, cache writes at 1.25x (5-minute) or 2x (1-hour), cache reads priced per model, output, fast mode at 2x. Subagents included.
Conservative savingsTrim savings count only what Claude would really have read, and stop at the next compaction.
PrivateNo network calls. Reads ~/.claude/projects, writes to ~/.tokenreceipts. Plans and discounts can make your real bill differ.
